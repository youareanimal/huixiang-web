# 回响 · 网页版

**打开浏览器，直接用 TeamSpeak。** 不用安装任何客户端，填上服务器地址就能进频道，像桌面客户端一样聊天、语音、传文件、共享屏幕。也提供 Windows 免安装启动器，双击即可进入。

> **安卓版（Android 客户端）**：<https://github.com/youareanimal/huixiang>
>
> 本项目与安卓版是同一个「回响」的不同端。本项目的隐私协议、用户协议及其他相关协议与政策，均与安卓版仓库保持一致，具体内容请以该仓库中的对应文件为准。

> **注意**：本项目仍处于开发阶段。服务器页已从旧版 `ServerPage` 重构为新的 `ServerHome`。频道管理、频道排序、成员踢出 / 封禁、说话方式切换、账号头像上传等能力均已接入界面；改名自己与摄像头共享入口本期**不提供**（详见文末「开发计划」）。欢迎反馈与指正。

## 功能

> 下列为当前版本**实际可用**的能力；尚未接入界面的功能统一列在「开发计划 · 界面接入中」。

**连接与账号**

- 匿名游客即可进入，也支持登录 myTeamSpeak 账号；登录后连接会带上账号身份，服务器可显示账号徽章。游客可自行填写昵称。
- 支持服务器地址（含 `ts3server://` 邀请链接与端口）、昵称、服务器密码，以及直接进入指定频道（含频道密码）；若站主设置了访问口令，连接时需要填写。
- 「记住登录」：登录一次后 30 天内免重输密码（可在服务端调整或关闭）。
- 云书签：登录后读取账号的服务器书签，点一条即自动填入地址、昵称和服务器密码。
- 云身份：登录后可选择账号同步的服务器身份，使用相同身份的设备可获得同一组权限；同时连接的数量由各服务器控制。
- 信息栏同时显示两段延迟：浏览器 ↔ 网关、网关 ↔ TeamSpeak 服务器。

**频道与成员**

- 频道列表：名称、频道图标、密码锁标记、分隔符频道，可按父级折叠；支持按频道名 / 成员名搜索，双击进入频道（有密码的弹窗输入）。频道描述与在线人数显示在聊天区顶部。
- 频道管理：左栏「+」新建频道，频道行「⋯」可编辑 / 删除，并在菜单里用**上移 / 下移**调整同级排序（权限由服务器判定）。
- 成员列表：头像、昵称、说话状态、离开、直播中；悬停查看资料卡（频道、身份组，可单独调节某人音量）。
- 频道成员管理：管理员可在成员行「⋯」里将成员**踢出频道 / 踢出服务器 / 封禁**（封禁可选时长并填写原因）。
- 戳一戳：成员资料卡右上角有「戳一戳」按钮，点击后对方收到「XX 戳了戳你」提示；可在「设置 → 戳一戳」里自定义戳一戳的文案（留空用默认的「戳了你一下」）。不进聊天记录。
- 暂离（Away）：可切换暂离并填写离开留言，实时同步到服务器与所有客户端。
- 成员进出本频道时，右下角文字提示并播放提示音。

**语音**

- 双向 Opus 语音，麦克风与扬声器静音状态实时同步到服务器；两路音量可分别调节。
- 默认「自动」说话方式：本地按音量检测，安静时不发送、不占上行。
- 离开 / 掉线后 14 天内再进会自动恢复上次的麦克风 / 扬声器静音偏好。
- 提示：语音功能需要浏览器支持 WebCodecs。

**文字**

- 频道消息收发（输入框支持多行，Enter 发送、Shift+Enter 换行）。
- 频道聊天历史：默认保存在本机浏览器（IndexedDB，每个频道最多 300 条 / 90 天），滚动到顶部可继续向前翻页；若网关配置了 `CHAT_HISTORY_DIR`，还会在服务端保留一份，换浏览器 / 换设备也能补上。
- 私聊从「好友」抽屉进入：对方在线时走服务器私聊（官方客户端可见），离线时走云端聊天（Matrix）。

**屏幕共享**

- 通过 WebRTC 与对方直连共享屏幕，既能观看别人的直播，也能自己开播；支持全屏与静音。
- 共享为点对点（mesh），观看的人越多，发布者上行带宽占用越高。
- 部署了 LiveKit 时还能用「共享屏幕 - 网页直播（LiveKit）」：主播只上行一路，媒体经 SFU 分发，适合人多或上行带宽有限；同频道的网页成员可订阅观看，一个频道可多人同时开播、观众按人选择看谁的画面（原生 TeamSpeak 客户端不参与这条链路）。

**频道文件**

- 浏览、下载、上传、新建文件夹、改名、删除频道文件区里的文件。
- 文件保存在 TeamSpeak 服务器上，安卓 App、官方客户端与网页版看到的是同一批。
- 上传、删除、改名等写操作均带二次确认，并按服务器权限裁决。

**好友与账号**

- 好友列表显示昵称 / 备注；在线状态与云聊天在「好友」抽屉里一并呈现。
- 成员头像按「账号 > 服务器 > myTS > 首字母」逐级回退显示。
- 账号头像：登录后可在「设置」抽屉里上传 / 更换 / 删除自己的账号头像（自动压图后同步到 myTeamSpeak，游客不显示入口）。

**其他**

- 桌面通知：收到私聊、或页面不在前台 / 不在当前频道时收到频道消息，会弹系统通知（顶栏「设置」里开关）。
- 可作为 PWA 安装到桌面或手机主屏。
- 随时主动离开服务器，之后可再次连接。

## 使用

### 在浏览器中打开

访问部署好的回响网页地址（例如 <https://ts.xinmouren.cn/>），按页面提示填写服务器地址、昵称即可进入；如需账号功能，在连接页登录 myTeamSpeak。

### Windows 桌面启动器（免安装）

仓库根目录附带两个**等价**的启动器，方便不想开浏览器、或没有开发环境的人直接双击进入网页版：

- **`回响.exe`** —— 带回响图标，双击即用（推荐）。
- **`回响.bat`** —— 无图标备选；若 exe 被安全软件误拦，可改用此文件，或直接用记事本打开审查逻辑。

两者行为一致：自动查找本机 Microsoft Edge，用一个**独立配置目录**（`%LocalAppData%\HuixiangLowMem`，不干扰日常 Edge）以 `--app=https://ts.xinmouren.cn/` 启动回响网页版，并加 `--disable-extensions` 禁用所有扩展以尽量省内存。**首次使用需在弹出的页面里登录一次**，之后自动记住。

- 改服务器地址：`回响.exe` 内置固定为 `https://ts.xinmouren.cn/`；`回响.bat` 可用记事本改顶部的 `APP_URL`。
- `回响.exe` 若探测到首选目录不可写，会自动回退到 `%TEMP%`，再退到程序所在目录，避免「访问被拒绝」。
- 自编译 exe 首次运行可能触发 SmartScreen「未知发布者」，点「更多信息 → 仍要运行」即可。

### 自己部署

想自建一套回响，可按 [deploy/DEPLOY.md](deploy/DEPLOY.md) 从空服务器一路部署到验收；最简单的 Docker 方式：

```bash
docker build -t huixiang-web .
docker run -d --restart=always \
  -p 127.0.0.1:8080:8080 \
  -e ACCESS_TOKEN=你的访问口令 \
  -e ALLOWED_ORIGINS=https://你的域名 \
  -v "$PWD/chat-history:/app/chat-history" \
  --name huixiang-web huixiang-web
```

> 需要「网页直播（LiveKit）」时，单容器方式不够：用 [deploy/docker-compose.sfu.yml](deploy/docker-compose.sfu.yml) 整套启动，或在单容器外另起 LiveKit 并设置 `LIVEKIT_URL` / `LIVEKIT_API_KEY` / `LIVEKIT_API_SECRET`，详见 [deploy/DEPLOY.md](deploy/DEPLOY.md) 第 8.1 节。

常用环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8080` | 监听端口 |
| `HOST` | `127.0.0.1` | 监听地址。镜像内为 `0.0.0.0` 以便端口映射；宿主机对外仍建议只绑 `127.0.0.1` 并走 Nginx TLS |
| `WEB_DIST` | `client/dist` | 前端构建产物目录 |
| `ACCESS_TOKEN` | 空 | 共享访问口令。**不设等于把这台机器当免费代理**，公开部署务必设置 |
| `ALLOWED_ORIGINS` | 空 | 允许的页面来源，逗号分隔；留空只接受同源 |
| `CHAT_HISTORY_DIR` | `chat-history` | 频道聊天历史落盘目录；不设则仅存内存 |

前端在 `client`（React + Semi Design），构建产物（`client/dist`）由网关一并托管；开发与构建细节见 [client/README.md](client/README.md)。

## 项目结构

本仓库由前端（**client**）、网关（**gateway**）、协议栈（**tsproto**）三部分组成，另含部署与启动器相关文件：

```text
huixiang-web/
├─ client/                 前端：React 18 + TypeScript + Vite + Semi Design
│  ├─ index.html
│  ├─ vite.config.ts
│  ├─ public/              静态资源、PWA 图标、manifest、Service Worker
│  └─ src/
│     ├─ main.tsx          入口（生产构建下注册 Service Worker）
│     ├─ App.tsx           应用根组件：连接生命周期、账号 / 语音 / 串流状态、聊天历史
│     ├─ gateway.ts        与网关的 WebSocket 通信、请求/推送分发

│     ├─ files.ts          频道文件字节（HTTP 下载 / 上传）

├─ gradlew / gradlew.bat   Gradle 包装器（构建网关与协议栈）
├─ 回响.exe / 回响.bat     Windows 免安装启动器
└─ CHANGELOG.md / LICENSE / PRIVACY.md / README.md
```

- **`client/`**：浏览器前端，构建产物 `client/dist` 由网关直接托管。
- **`gateway/`**：WebSocket / HTTP 网关，负责浏览器连接、会话管理、文件与静态资源路由；构建时通过 `kotlin.srcDir` 直接引用 `tsproto` 源码，因此两者需一起构建。
- **`tsproto/`**：TeamSpeak 协议栈，独立、无 Android 依赖，可单独复用。其协议实现移植自开源项目 [PocketTS](https://github.com/korppujauho/pocketts)（详见文末「[致谢](#致谢)」）。
- 运行时会在工作目录下生成 `chat-history/`（频道聊天历史，可用 `CHAT_HISTORY_DIR` 改到别处）。

## 浏览器要求

| 能力 | 需要 |
|---|---|
| 语音 | WebCodecs（`AudioDecoder` / `AudioEncoder`）：Chrome/Edge 94+、Firefox 130+、Safari 26+（iOS 26+） |
| 文字、频道等 | 任何现代浏览器 |

不支持 WebCodecs 时页面顶部会提示，文字和频道功能照常可用。

- [✓] **头像显示**：成员头像按「账号 > 服务器 > myTS > 首字母」逐级回退
- [✓] **连接**：地址 + 端口 + 昵称 + 服务器密码 + 访问口令 + 直接进指定频道（含频道密码）；支持邀请链接
- [✓] **服务器页重构为 ServerHome**：频道列表 + 成员 + 聊天 + 控制条的一体化布局
- [✓] **频道列表**：图标、密码锁、分隔符、折叠、按频道 / 成员搜索、双击进入（含频道密码）；频道描述与在线人数显示在聊天头部

- [✓] **戳一戳**：成员资料卡右上角按钮，网关用 `clientpoke` 发送，对方收到「XX 戳了戳你」提示；可在设置里自定义文案；不进聊天记录
- [✓] **成员进出提示**：本频道有人进出时右下角文字提示并响一声
- [✓] **暂离（Away）**：可切换暂离并填写离开留言，实时同步
- [✓] **PWA / 安装**：可安装到桌面或手机主屏；断网时能打开外壳并提示需联网
- [✓] **切换频道**：含频道密码
- [✓] **文字**：频道消息与私聊收发
- [✓] **聊天历史**：本地 IndexedDB（300 条 / 90 天）+ 网关可选保留一份
- [✓] **静音**：麦克风与扬声器状态同步到服务器，离开 / 掉线后 14 天内再进自动恢复

## 隐私协议

回响网页版与安卓版遵循一致的隐私原则：无应用自有账号、无广告、无分析或崩溃上报。

- **账号与身份。** 登录凭据经加密连接交给网关，网关持有会话及用于连接的云身份私钥，请使用可信网关。若在登录页勾选“记住密码”，浏览器本地存储会保存可逆编码的邮箱和密码；账号会话另可通过 HttpOnly cookie 恢复。
- **频道聊天历史默认只存在本机浏览器**（IndexedDB），不上传；仅当网关明确配置了 `CHAT_HISTORY_DIR` 时才会在服务端落盘一份（只含频道消息、不含私聊，最多 90 天 / 每会话 300 条）。
- **建议对外部署启用 HTTPS。** 公开部署时请配置 TLS，并尽量设置访问口令，避免服务被他人当作代理使用。
- **文件与头像**访问使用仅对当前标签页有效的临时令牌，断开即失效。
- 完整说明见 [PRIVACY.md](PRIVACY.md)；安卓版的完整隐私说明见 <https://github.com/youareanimal/huixiang/blob/main/PRIVACY.md>，两者保持一致。
